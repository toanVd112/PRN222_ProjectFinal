# Screen Descriptions

| # | Feature | Screen | Description |
|---|---|---|---|
| 1 | Authentication | Login Screen | This page allows users to enter their email/user code and password to log in. |
| 2 | Authentication | Forgot Password Screen | Allows users to request a password reset link by entering their registered email. |
| 3 | Manage Personal Profile | My Profile Screen | Users can view and update their personal information such as full name and phone number. |
| 4 | Change Password | Change Password Screen | Users can securely change their current password and auto-logout upon success. |
| 5 | View Dashboard | Admin Dashboard | Admin screen after logging in, displaying system statistics and overview metrics. |
| 6 | Manage User Account | Manage Users | Admin can search, filter, and view a list of all user accounts in the system. |
| 7 | Manage User Account | Create/Edit User Form | Admin can add, edit, lock, or delete user accounts and assign specific roles. |
| 8 | Manage Room | Manage Rooms | Admin can add, edit, or delete classrooms and view room capacities. |
| 9 | Manage Equipment Category | Manage Categories | Admin can add, edit, or delete equipment classifications. |
| 10 | Approve Equipment Disposal | Equipment Disposals | Admin can review, approve, or reject equipment disposal requests submitted by technicians. |
| 11 | Add/Update Equipment | Equipment List | Technician home screen displaying all equipment with search and filter capabilities. |
| 12 | Add/Update Equipment | Add Equipment Form | Technician can register new equipment details and initial room assignments. |
| 13 | Add/Update Equipment | Edit Equipment Form | Technician can update existing equipment information and operational status. |
| 14 | Manage Equipment Location | Transfer Room Screen | Technician can transfer equipment between rooms and log the transfer history. |
| 15 | Process Incident Report | Process Incident Screen | Technician can review incidents, update processing status (In Progress, Resolved), and log repair notes. |
| 16 | Create Maintenance Ticket | Create Maintenance Ticket | Technician can log external repair details, expected costs, and return dates for broken equipment. |
| 17 | View Room Equipment | Room Equipment View | Lecturer home screen to view the equipment list and operational statuses in their assigned classroom. |
| 18 | Submit Incident Report | Report Incident Form | Lecturer can report broken or missing equipment and upload evidence images. |
| 19 | Track Incident Report | Track Incidents List | Lecturer can track the real-time processing status of their submitted incident reports. |
